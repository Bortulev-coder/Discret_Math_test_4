ОСНОВЫ БЕЗ ПРОБЕЛОВ

Всего два значения.
Много возможностей.

Булева функция получает нули и единицы
и возвращает 0 или 1. Начнём с языка формул.

Как читать формулу

0 означает «ложь», 1 — «истина». Для двух переменных есть четыре набора: 00, 01, 10, 11. Каждая операция задаёт свой результат на этих наборах.

Три места, где легко ошибиться

  • ИЛИ допускает обе единицы: 1 ∨ 1 = 1.
  • XOR требует различия: 1 ⊕ 1 = 0.
  • Импликация ложна только на 10: 1 → 0 = 0. Во всех остальных случаях она равна 1.

Порядок действий на этом сайте

¬   затем ∧   затем ⊕   затем ∨   затем →   затем ↔

Скобки выполняются первыми. Цепочка импликаций читается справа: x → y → z = x → (y → z). В разных курсах приоритет XOR отличается, поэтому в спорных местах всегда ставь скобки.

Как построить таблицу

  1. Выпиши переменные. Для n переменных нужно 2ⁿ строк: 2 переменные — 4, 3 — 8, 4 — 16.
  2. Перечисли наборы в двоичном порядке. Для x, y, z: 000, 001, 010, 011, 100, 101, 110, 111. Последняя переменная меняется чаще всех.
  3. Добавь промежуточные столбцы. Сначала вычисли выражения внутри скобок, затем результат всей формулы.
  4. Прочитай последний столбец сверху вниз. Это вектор значений функции. Сохрани порядок строк: он нужен для полинома.

ВТОРОЙ ЭТАП

Полином Жегалкина.
Только И и XOR.

Это запись функции через XOR (⊕), произведения переменных (И) и константу 1. Каждая переменная в одном произведении встречается не более одного раза. У каждой булевой функции такой полином единственный.

P(x, y) = a₀ ⊕ a₁y ⊕ a₂x ⊕ a₃xy

Коэффициенты aᵢ — только 0 или 1. Если коэффициент равен 0, слагаемое не пишем. Для трёх переменных возможны члены: 1, z, y, yz, x, xz, xy, xyz.

A ⊕ A = 0Одинаковые члены сокращаются парами.
A ⊕ 0 = AНоль можно убрать.
x · x = xСтепени переменной не нужны.
¬x = 1 ⊕ xОтрицание заменяется XOR с 1.
МЕТОД ДЛЯ БУМАГИ

Треугольник XOR

Запиши вектор горизонтально. Под ним вычисли XOR каждой пары соседей. Повторяй, пока не останется одно число. Первые числа строк сверху вниз — коэффициенты полинома. Это та же схема, что в викиконспекте ИТМО, повёрнутая на 90°.

  1. Для x ∨ y вектор равен 0 1 1 1.
  2. Ниже: 0⊕1, 1⊕1, 1⊕1. Получаем 1 0 0.
  3. Затем 1 0, затем 1.
  4. Левый край: 0, 1, 1, 1. Члены в порядке 00, 01, 10, 11: 1, y, x, xy.

Почему 01 — это y?
Код коэффициента указывает, какие переменные входят в произведение: 01 → y, 10 → x, 11 → xy. Код 00 соответствует константе 1. Это коды членов полинома, а не их значения.
Второй способ: неопределённые коэффициенты (страница 63)

Для x ∨ y начни с P = a₀ ⊕ a₁y ⊕ a₂x ⊕ a₃xy. Подставляй наборы и находи по одному новому коэффициенту:

  • 00: 0 = a₀, значит a₀ = 0.
  • 01: 1 = a₀ ⊕ a₁, значит a₁ = 1.
  • 10: 1 = a₀ ⊕ a₂, значит a₂ = 1.
  • 11: 1 = 0 ⊕ 1 ⊕ 1 ⊕ a₃, значит a₃ = 1.

Получаем тот же результат: y ⊕ x ⊕ xy. Здесь 1 ⊕ 1 = 0, поэтому последняя строка даёт a₃ = 1.

Как получить полином преобразованиями формулы

¬A = 1 ⊕ A   ·   A ∨ B = A ⊕ B ⊕ AB   ·   A → B = 1 ⊕ A ⊕ AB

Например, ¬x ∧ y = (1 ⊕ x)y = y ⊕ xy. Скобки раскрываются как в обычной алгебре, но одинаковые члены сокращаются по XOR. Не заменяй обычное ИЛИ на XOR без дополнительного произведения AB.

ТРЕТИЙ ЭТАП

Пять вопросов
к одной функции.

Функция может входить сразу в несколько классов. Для «да» нужно выполнить условие полностью. Для «нет» достаточно одного контрпримера.

T₀

Сохраняет ноль?

f(0, …, 0) = 0

Посмотри на первую строку таблицы. У x ∧ y там 0, поэтому x ∧ y ∈ T₀. У ¬x там 1 — значит ¬x ∉ T₀.

ПЕРВАЯ СТРОКА
T₁

Сохраняет единицу?

f(1, …, 1) = 1

Посмотри на последнюю строку. Для x ∨ y ответ «да», для x ⊕ y — «нет», потому что 1 ⊕ 1 = 0.

ПОСЛЕДНЯЯ СТРОКА
S

Самодвойственная?

f(¬x₁, …, ¬xₙ) = ¬f(x₁, …, xₙ)

Сравни противоположные наборы: 000 с 111, 001 с 110, 010 с 101, 011 с 100. Во всех парах значения должны различаться. В двоичном порядке это первая строка с последней, вторая с предпоследней и так далее.

Пример: ¬x ∈ S, потому что значения на 0 и 1 равны 1 и 0. Для x ∧ y пара 01 и 10 даёт 0 и 0, поэтому x ∧ y ∉ S.

ПРОТИВОПОЛОЖНЫЕ ПАРЫ
M

Монотонная?

α ≤ β покоординатно ⇒ f(α) ≤ f(β)

Если заменять входные нули единицами, результат не должен падать с 1 до 0. Достаточно проверить все переходы, в которых меняется один входной бит 0 → 1.

Для XOR: 01 ≤ 11, но f(01) = 1 > f(11) = 0. Значит x ⊕ y ∉ M. Наборы 01 и 10 несравнимы: одна координата растёт, другая убывает.

Соседние строки — неверный общий критерий: соседние наборы могут быть несравнимы, а сравнимые пары не всегда соседствуют.

ВСЕ РЁБРА КУБА
L

Линейная?

P = a₀ ⊕ a₁x₁ ⊕ … ⊕ aₙxₙ

В готовом полиноме нет произведений двух и более разных переменных. Константа 1 разрешена. Поэтому 1 ⊕ x ⊕ y ∈ L, а x ⊕ xy ∉ L.

В теме классов Поста L включает аффинные функции, то есть свободный член допускается. Функции 0 и 1 тоже входят в L.

СТЕПЕНЬ НЕ ВЫШЕ 1
Дополнительно: как это связано с критерием Поста

Система функций функционально полна тогда и только тогда, когда для каждого из пяти классов в системе найдётся хотя бы одна функция вне этого класса. Эти функции могут быть разными. В твоём задании требуется определить классы одной функции; проверять полноту системы нужно только если это отдельно попросят.

ПОЛНЫЙ РАЗБОР

Одна задача.
От начала до ответа.

Возьмём f(x, y, z) = (x → y) ⊕ z.
Выбирай этап и следи за вычислениями.

Сначала скобки, затем XOR

В столбце x → y ноль появляется только при x = 1, y = 0. Значение z либо сохраняет этот результат (z = 0), либо переворачивает его (z = 1).

Например, набор 101:
(1 → 0) ⊕ 1 = 0 ⊕ 1 = 1.

Вектор значений: 10100110.

Строим треугольник

Каждая новая строка — XOR соседей предыдущей. Нажми «Следующая строка», чтобы пройти вычисления.

Проверка преобразованием: x → y = 1 ⊕ x ⊕ xy. Поэтому f = 1 ⊕ x ⊕ xy ⊕ z. Порядок слагаемых на результат не влияет.

Каждый ответ — с обоснованием

Итог: f ∉ T₀, f ∉ T₁, f ∉ S, f ∉ M, f ∉ L.

ПЕРЕД РАБОТОЙ

Всё нужное.
На одном листе.

Алгоритм решения

  1. Выпиши 2ⁿ наборов от 00…0 до 11…1.
  2. Вычисли подформулы и столбец f.
  3. Построй треугольник XOR. Левый край — коэффициенты.
  4. Сопоставь коэффициентам члены по двоичным кодам.
  5. Проверь T₀, T₁, S, M и L. Запиши обоснования.

Пять критериев

T₀
Первая строка f равна 0.
T₁
Последняя строка f равна 1.
S
На всех противоположных наборах значения различны.
M
При 0 → 1 на любом входе нет падения f: 1 → 0.
L
В полиноме нет произведений степени ≥ 2.

Самопроверка

  • Строк ровно 2ⁿ, наборы не повторяются.
  • ИЛИ и XOR не перепутаны.
  • Полином совпадает с f на всех наборах.
  • Для каждого «не принадлежит» есть причина.
  • Подготовлены ручка и листы в клетку.

Частые ошибки

«В столбце f есть переход 1 → 0, значит не M». Сначала проверь, сравнимы ли наборы: у монотонной функции f = y переход 01 → 10 даёт 1 → 0, но эти наборы несравнимы. «В формуле есть xy, значит не L». Сначала приведи её к полиному: произведения могут сократиться. «У S значения должны совпадать». На противоположных наборах они должны различаться.
