# Булева лаборатория

Учебный сайт для подготовки к работе по дискретной математике.

**Сайт:** https://bortulev-coder.github.io/Discret_Math_test_4/

## Что внутри

- Логические операции и построение таблиц истинности.
- Полином Жегалкина: треугольник XOR, неопределённые коэффициенты, преобразования формул.
- Пять классов Поста: T₀, T₁, S, M, L с объяснениями и контрпримерами.
- Калькулятор функций до четырёх переменных: ввод формулы или вектора значений.
- Шесть задач с проверкой таблицы, полинома и классов.
- Памятка для печати.

## Запуск

Откройте `index.html` в браузере. Установка зависимостей и сборка не нужны.

`index.html` находится в корне репозитория. GitHub Pages публикует ветку `main`, каталог `/ (root)`.

Все вычисления выполняются в браузере. Прогресс тренажёра хранится локально на устройстве. Шрифт Manrope загружается через Google Fonts; без интернета используется системный шрифт.

## Проверка вычислений

При установленном Node.js:

```sh
node test-engine.cjs
```

Проверяются примеры, разбор формул, константы и все 256 булевых функций трёх переменных. Для них полином сверяется с исходной функцией на каждом наборе, а монотонность — со всеми сравнимыми парами.
